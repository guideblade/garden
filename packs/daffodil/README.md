# Daffodil

Astro-centered frontend development extension pack roll-up for VS Code.

Its main focus is vanilla Astro augmented by SCSS and TypeScript.

![Daffodil](assets/daffodil.png)

## Included Packs

- Daffodil Main
- Daffodil Markup
- Daffodil Styles
- Daffodil Logic
- Daffodil Context
- Daffodil Content
- Daffodil Appearance
